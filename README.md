# OLED-tRENDING_EXPRESSION# OLED Robot Faces for Arduino UNO

A collection of animated OLED robot faces built using an Arduino UNO and a 0.96-inch SSD1306 OLED Display. This repository contains multiple eye and face animations including anime eyes, blinking effects, sleeping expressions, and classic robot eyes.

## Features

- Anime Face V1
- Anime Face V2 (Blinking Eyes)
- Classic Robot Eyes
- Thin Eyebrow Expression
- Sleeping Animation
- Smooth Eye Movement
- OLED Facial Expressions
- Beginner-Friendly Arduino Code

## Hardware Required

- Arduino UNO / Nano
- SSD1306 OLED Display (128×64, I2C)
- Jumper Wires
- Breadboard (Optional)

## OLED Connections

| OLED Pin | Arduino UNO |
|-----------|------------|
| VCC | 5V |
| GND | GND |
| SDA | A4 |
| SCL | A5 |

### Wiring Diagram

OLED SSD1306 (I2C)
VCC → 5V
GND → GND
SDA → A4
SCL → A5

## Required Libraries

Install the following libraries from the Arduino Library Manager:

- Adafruit GFX Library
- Adafruit SSD1306 Library

## Getting Started

1. Connect the OLED display according to the wiring table.
2. Install the required libraries.
3. Open any sketch from this repository.
4. Select your Arduino board and COM port.
5. Upload the code.
6. Enjoy animated robot faces on your OLED display.
